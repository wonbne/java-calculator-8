# 문자열 덧셈 계산기

## 기능 요구 사항

### 1. 문자열 입력 받기
- 사용자가 계산할 문자열을 입력한다.
- 입력값이 빈 문자열(`""`)이면 0을 반환한다.

### 2. 구분자 처리
- **기본 구분자**: 쉼표(`,`)와 콜론(`:`)
   - 문자열을 기본 구분자를 기준으로 분리하여 숫자를 추출한다.
   - 예: `"1,2:3"` → 6
- **커스텀 구분자**
   - 입력 문자열이 `"//구분자\n"` 형식으로 시작하는 경우 커스텀 구분자를 추가
   - 커스텀 구분자를 포함하여 문자열을 분리하고 숫자를 추출한다.
   - 예: `"//;\n1;2;3"` → 6

### 3. 계산 로직
- 구분자를 기준으로 문자열을 분리하여 각 숫자를 더한다.
- 분리된 숫자가 하나일 경우 해당 숫자를 그대로 반환한다.

### 4. 예외 처리
- 문자열에 숫자 이외의 문자가 포함되면 `IllegalArgumentException` 발생
- 음수 값이 포함되면 `IllegalArgumentException` 발생
- 프로그램은 예외 발생 시 즉시 종료

### 5. 출력
- 계산된 결과를 사용자에게 출력
